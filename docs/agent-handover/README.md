# 🤖 Agent Handover Guide

Welcome to the **Digital Access Now (DAN)** project repository!

If you are a new AI Agent stepping in to continue development, **please read through the files in this directory before modifying the codebase**. This will prevent you from overwriting established branding rules or breaking the authentication structure.

### Reading Order:
1. File: `01-project-context.md` - Core tech stack, `.env.local` requirements, and Supabase config.
2. File: `02-features-and-architecture.md` - Role-based definitions (Admin, Chapter, Volunteer).
3. File: `03-theme-and-ui.md` - Strict rules regarding the `#00BCD4` theme, the lack of purple elements, and the exact constraints of the ImgBB Logo PNG.
4. File: `04-implementation-plan-phase3.md` - The exact immediate next steps required to wire the frontend `<form>` submits to the Supabase APIs to ensure the mocked data becomes real data.
5. File: `05-work-log-apr-2026.md` - Recent fixes, Supabase health issue definition, and next steps for recovery.

**Current Task Status**: Phase 1 (Auth/Routing) and Phase 2 (Frontend React UIs) are **100% complete**. Development is currently paused at the very beginning of Phase 3 (API Wiring).
