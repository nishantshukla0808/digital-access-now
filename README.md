# Digital Access Now

A modern, responsive website for Digital Access Now - one of the world's largest digital equity organizations dedicated to breaking barriers to digital access so every community can thrive.

## 🌐 About

Digital Access Now empowers underserved communities worldwide by providing digital access, education, and resources. We envision a world where digital tools and knowledge are equally accessible to all, regardless of geographical location, economic status, or background.

## ✨ Features

- **Modern Design**: Built with Next.js 16 and Tailwind CSS v4
- **Responsive Layout**: Fully responsive design that works on all devices
- **Dynamic Hero Carousel**: Auto-rotating carousel showcasing our mission and impact
- **Team Showcase**: Meet our leadership team with professional profiles
- **Interactive Navigation**: Smooth navigation with dropdown menus
- **SEO Optimized**: Built with Next.js for optimal performance and SEO

## 🚀 Tech Stack

- **Framework**: [Next.js 16.0.10](https://nextjs.org/) (App Router with Turbopack)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Poppins & Montserrat (Google Fonts)
- **Package Manager**: pnpm

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/nishantshukla0808/digital-access-now.git
cd digital-access-now
```

2. Install dependencies:
```bash
pnpm install
```

3. Run the development server:
```bash
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
